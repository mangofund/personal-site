05规则

战斗公式

生命 HP = DEF × 2
伤害 = max（ ATK × 10% , ATK − DEF × 0.5 ）

例：ATK 12,000 打 DEF 8,000 → 伤害 = max（1,200， 12,000 − 4,000）= 8,000，对方生命 16,000，两击倒。每回合我方先手，对方存活则反击。单挑至一方生命归零，胜者保留剩余生命迎战对方下一张；先打光对方 5 张者胜。30 回合未分胜负，按双方剩余总生命多者判胜。
