# 实图配文

给一段内容配一张与内容对应的真实照片，再把文字用代码排上去，出 PNG 卡片。

图片是下载到的真实照片。文字是 HTML 渲出来的，一个字都不会错。主图不用 AI 生图。

## 什么时候用

- 文章、帖子要一张配图卡片
- 标题加要点要做成图发出去
- 封面要配真图，不想用 AI 画
- 文章封面三选一之一（另两个是 cover_image_gen 纸雕、scrapbook_collage 手账），每次写完长文三张一起出，用户从三张里选
- 只要纯图不要字（无文字版，见下）

不用的时候：

- 只要纯文字，不要图
- 要 AI 生图风格封面（用 cover_image_gen）
- 要数据图表（用 lieflat-charts）

## 五步做一张卡

1. 定内容。标题逐字抄原文。要点最多 3 条，每条一句话。数字逐个对原文，没有来源的数字不上卡。
2. 找真图。用户给图就用用户的。没给，按顺序取：Unsplash → Pexels → Flickr CC → 直接搜索。下载到本地，写 SOURCES.md。Unsplash、Pexels 要 key，没有 key 就跳过，不硬等。Flickr 静态图床对本机出口 IP 间歇限流，下载加浏览器 User-Agent，限流就等几秒重试。
3. 选画板。21:9 公众号头图 2100×900；1:1 方图 1080×1080；16:9 X 图 1600×900。不做小红书。
4. 排字渲图。拷 templates 里的种子，填文案，跑 `node scripts/render.mjs` 出 PNG。
5. 睁眼验。打开 PNG 逐字核文字，核图片和内容对得上，核 SOURCES.md 有来源。三样都过才交付。

## 硬规矩

- 主图只用真实照片或用户给的截图。AI 生图不能当主图。
- 没照片用剪影占位，绝不编人脸。
- 文字压图上，先看主体：不盖人脸，不盖关键物。字放暗处加深色块，放亮处加浅色块，字必须读得清。
- 数字只用原文里的，逐个核对。不编数字，不编事件细节。
- 副标题不写事实断言。没把握就只放标题。
- 每张卡的图片来源写进 SOURCES.md。商用前再核一次授权。
- 出图前先给用户看过，不直接发出去。

## 画板与模板

- `templates/template-cover.html`：左文右图。21:9 和 16:9 共用，render.mjs 按 --width/--height 改卡片尺寸。
- `templates/template-square.html`：上图下文。1:1。
- 颜色、字号、留白都写在模板里。改文案只改字，不改样式。

## 无文字版

- 只要纯图、不要字的时候，用 `templates/template-photo-only.html`：整张卡就是照片本身，满铺，不加任何字。
- 卡面不带字，来源不写在图上，只记 SOURCES.md。商用前再核一次授权。
- 验卡只验两样：图片是真实照片、和内容对得上；PNG 尺寸和画板一致。

## 渲染

Playwright 路（默认）：

```
cd scripts
npm install   # 只装 playwright-core，浏览器用本机缓存
node render.mjs --html <卡片.html> --out <输出.png> --width 2100 --height 900
```

Playwright 两次跑不通，走 PIL 叠字：

```
python3 overlay_pil.py --image <图.jpg> --title <标题> --out <输出.png>
```

PIL 路只做兜底：字叠在图上，没有版式。

## 验卡清单

- 文字逐字和原文一致
- 数字逐个和原文一致
- 图片是真实照片，和内容对得上
- SOURCES.md 有图来源、作者、授权
- PNG 尺寸和画板一致
