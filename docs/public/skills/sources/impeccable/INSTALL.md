# Install full Impeccable (optional)

This MangoFund store package is a **subset** focused on critique / audit / polish.

For the full CLI, all commands, and the self-contained launcher:

```bash
# npm
npx impeccable --help

# or clone upstream
git clone https://github.com/pbakaus/impeccable.git
# then follow upstream README / cursor-plugin install
```
