# 口播分镜（koubo-storyboard）

把「资料堆砌」改成「有人在跟你讲一件事」：先写可念出口的口播剧本，再按叙事拐点出证据帧插图，同一剧本分发到视频、X Article、短帖。

## 何时用

- 用户要「像 LabSpeculation / 投机实验室那种」人性化长文、故事帖、X Article
- 复盘、安全事件、链上追踪、产品发布、行业故事需要娓娓道来
- 已有研报/官网稿，要改成口播体 + 贴合插图
- 同一内容要同时出 YouTube/口播视频 + 长图文

不适合：纯教程步骤清单、API 文档、只要去 AI 味润色（用去AI味写作）、只要一封面（用封面图生成）。

## 总原则

1. **剧本先于排版。** 禁止先写「背景 / 影响 / 结论」四段论再润色。先写能念 8～15 分钟的口播稿。
2. **一段一事、短句可念。** 独立短段；数字用口播说法（「百分之八」「七分钟都不到」），少用论文腔。
3. **图是分镜，不是装饰。** 每张图卡在叙事拐点，带一句字幕结论；证据优先真实截图。
4. **信息可核。** 时间戳、金额、地址、公告原文必须来自素材层，不编造。
5. **保留枝节。** 私人立场、读者称呼、情绪插曲故意留下，用来盖住工业化痕迹。

## 五层流水线

### 1. 素材层（只收事实条）

从链上浏览器、官方推文/公告、第三方报告、采访摘录收集条目。每条写成：

`时间 | 事实一句 | 来源类型（推文/公告/链上/报道）| 原文或链接`

缺时间戳的条目标「待核」，写进剧本前必须补齐或删掉。

### 2. 剧本层（关键）

强制口播结构：

1. **钩子（30～60 秒）** — 第一人称怀疑或反常识一句：「这单我来回看了好几遍。」
2. **时间轴复盘** — 按分钟/小时推进，每拍只推进一件事。
3. **每 3～5 拍插一句人声** — 「我注意到…」「各位要是…」「怪的是…」
4. **技术点生活化** — 术语后立刻跟比喻或可感结果（「签一张授权，执行权就交给合约了」「满打满算七分钟都不到」）。
5. **枝节一段** — 与主线相关但不「必要」的私人利害或情绪（表情包互怼、自己捏一把汗），写完再收回主线。
6. **收束** — 用户能立刻做的动作，或未解问题；不堆空泛「启示」。

禁止清单：副标题式小标题堆砌、「写在前面」、均匀「第一/第二/第三」、无立场的客观综述腔。

交付物：纯口播正文（可加轻量时间锚点），目标长度约 8～15 分钟可读完。

### 3. 分镜层

把剧本按拐点拆成表，一行一帧：

| # | 时间/拐点 | 口播句（字幕，≤18 字为佳） | 证据类型 | 画面备注 |
| --- | --- | --- | --- | --- |
| 0 | 封面 | 标题句 | 合成封面 | 人物/符号夸张可 |
| 1 | … | … | 推文截图 / 表格 / 流程图 / 公告 | 黄标标哪一句 |

拐点示例：历史对比、机制讲完、关键人物开口前、异常时长、手法揭晓、用户利益（提现/赔付）、旧案呼应。

通常 12～25 帧；不要均匀插空，不要无拐点硬配图。

### 4. 出图层（证据帧模板）

统一视觉语言（可按品牌换色，结构不变）：

- **底**：模糊实景或纯色纸面
- **中**：白卡片里的真实证据（推文/表格/流水），关键句 **黄高亮**
- **下**：字幕条 = 本帧口播结论句
- **角**：IP/旁白角色（可选）+ 账号/品牌水印

规则：

- 证据图尽量真实截图；少用纯生成插画撑场
- 封面可合成夸张（标题大字 + 符号人物）
- 每帧一句字幕，与口播同步，不另写文案
- 出图后核对：字幕无错字、黄标对准原句、水印不挡关键信息

封面可用站点的封面图技能；正文证据帧用截图工具 + 固定模板合成。

### 5. 分发层

同一剧本、同一套帧：

| 渠道 | 怎么用 |
| --- | --- |
| YouTube / 口播视频 | 念剧本；画面切证据帧 |
| X Article / 长帖 | 正文=口播稿；插图=关键帧 |
| 短帖引流 | 钩子 + 1 张封面或最强证据帧 + 链到全文/视频 |
| 官网长文 | 可保留口播节奏；站内规范另遵站点写作规则（免责声明、不写站外署名等） |

## 改造已有稿件（快速路径）

输入：一篇研报体/官网稿。输出：口播稿 + 分镜表（可选再出图）。

1. 抽出全部可核事实条 → 素材层
2. 扔掉原章节标题，按时间重排
3. 重写成口播短段，插入钩子/读者称呼/枝节
4. 标拐点 → 填分镜表
5. 若用户只要文案，停在分镜表；若要上线，再走出图层与分发

## 验收清单

- [ ] 大声读一遍不拗口；单段多不超过 3 句为佳
- [ ] 有至少 3 处第一人称或读者称呼打断「客观综述」
- [ ] 有至少 1 段非必要但真实的情绪/立场枝节
- [ ] 每个数字/时间能指回素材层
- [ ] 分镜表帧数 = 叙事拐点数；每帧有字幕句
- [ ] 插图不是「配图」，而是念到那句时该出现的画面

## 与其它技能的分工

- **去AI味写作**：已有成稿、只要清机器词 → 用它；要从结构改成故事 → 用本技能
- **封面图生成**：只要一张封面大图
- **图解设计 / 等轴测解剖**：机制需要示意框图时，可作分镜里的「流程图」证据类型
- **内容一稿多用**：口播母稿完成后再做多平台裁剪时可接力

## 输出格式（默认）

按用户要的深度给：

1. **口播正文**（可直接念/贴 Article）
2. **分镜表**（Markdown 表）
3. （可选）证据帧文件列表与字幕文案

不要只交「写作建议」；默认直接产出可执行的剧本与分镜。
