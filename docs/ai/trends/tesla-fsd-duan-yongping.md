# 特斯拉FSD年度最好的免费代言：段永平雇了一个月薪99美元没驾照的“司机”

马斯克可能没想到，特斯拉FSD在中国投资圈里最有说服力的一次广告，竟然来自段永平在雪球上的几句闲聊。

11月5日，有网友看到段永平分享生活日常，忍不住问了一句：“段哥竟然还要自己开车？”

段永平的回复很有意思：

“我有个司机，但司机没驾照。$99一个月要求也不能太高哈。”

这位没有驾照的司机，正是特斯拉的FSD（Full Self-Driving）。

有网友调侃，段永平这让国内的大小老板们情何以堪？

段永平随后解释：

“没有FSD找司机很正常啊。我其实也有真司机的，还有安保人员呢，只是不在一辆车上而已。”

11月24日，正在夏威夷度假的段永平又忍不住分享：

“在夏威夷能够租到带FSD的特斯拉，实在是太好了。以前旅行还要自己开车，现在到处都能用上FSD，真的爽啊。”

短短几句话，没有技术参数，没有算力介绍，没有端到端模型，也没有自动驾驶接管率。

却把特斯拉FSD的产品价值讲得明明白白。

**马斯克花多少广告费，都未必抵得上段永平这几句发自内心的感叹。**

![段永平雪球原帖截图：11 月 5 日的折叠屏与司机对话，以及夏威夷租到带 FSD 特斯拉的分享](/images/tesla-fsd-duan/fig-0.jpg)

## 一个不缺钱的人，为什么喜欢99美元的司机？

段永平当然请得起司机。

对他这个财富量级的人来说，雇佣私人司机的费用几乎可以忽略不计。但他依然愿意使用每月99美元的FSD，甚至出门度假时也希望租到带有这项功能的汽车。

这个行为比价格本身更值得研究。

私人司机需要沟通、协调时间，也意味着私人空间里多了一个人。

FSD提供了另外一种体验：保留自己出行的自由，同时减少驾驶操作带来的负担。

![特斯拉座舱：FSD 在中控屏上实时显示路况与行驶轨迹](/images/tesla-fsd-duan/fig-1.jpg)

想什么时候出门就什么时候出门，想去哪里就去哪里，不必因为行程变化提前通知别人。

对于普通人而言，99美元可能意味着性价比。

对于段永平而言，更有价值的可能是自由、隐私、便利性和掌控感。

**当一个产品能够吸引对价格不敏感、拥有充分替代选择的消费者时，它的价值就很难仅用便宜来解释。**

## 段永平无意中完成了一次产品价值验证

判断一款产品是否真正优秀，可以观察用户的三个行为：

- 第一次体验之后，是否愿意继续使用？
- 离开原有使用环境之后，是否主动寻找它？
- 没有任何商业激励，是否愿意向别人推荐？

从段永平公开分享的经历来看，FSD至少在他个人身上满足了这些特征。

在自己的车上使用FSD并不稀奇。

但到了夏威夷度假，能够租到带FSD的特斯拉，竟然成了一件值得专门发帖分享的事情。

![夏威夷海边停着的特斯拉 Model Y](/images/tesla-fsd-duan/fig-2.jpg)

这说明FSD已经在一定程度上改变了他的出行习惯和租车偏好。

就像习惯了智能手机的人，很难重新使用功能机；习惯了ChatGPT和Claude的程序员，也越来越难回到完全依靠手写代码的工作方式。

技术产品最理想的状态，是从新鲜感变成日常习惯，再从日常习惯变成用户选择其他产品时的必要条件。

互联网行业把这种现象称为用户黏性。

投资者则更关心它能否进一步形成品牌忠诚度、持续付费意愿和竞争壁垒。

当然，一个知名投资人的个人体验不能代表所有消费者，更不能直接证明FSD已经实现了大规模商业成功。

但它确实是一个值得观察的产品信号。

## 特斯拉卖的可能是一份数字劳动力

传统汽车公司的商业模式很简单：生产汽车、销售汽车、赚取制造利润。

车卖出去之后，厂商主要通过维修、保养、配件和金融服务继续获得收入。

特斯拉试图改变这种模式。

根据特斯拉美国官网，FSD监督版目前的订阅价格为每月99美元，并已转向订阅制销售。

这意味着每一辆符合条件、能够使用FSD的特斯拉，都有可能成为一个持续产生软件收入的终端。

我们可以算一笔简单的账。

| FSD付费订阅用户 |    每月收入 |     年化收入 |
| --------- | ------: | -------: |
| 100万      | 0.99亿美元 | 11.88亿美元 |
| 300万      | 2.97亿美元 | 35.64亿美元 |
| 500万      | 4.95亿美元 |  59.4亿美元 |
| 1000万     |  9.9亿美元 | 118.8亿美元 |

以上按照每月99美元、全年持续订阅计算，仅用于商业模式推演，并非特斯拉实际收入或业绩预测。

![FSD 订阅收入推演（年化）：100 万用户 11.88 亿美元，1000 万用户 118.8 亿美元](/images/tesla-fsd-duan/fig-3.jpg)

汽车制造需要工厂、原材料、工人、物流和库存。

FSD同样需要大量研发、算力、训练数据、硬件和安全验证投入，但成熟软件向更多兼容车辆交付的边际成本，相比重新制造一辆汽车，有望显著降低。

这就是资本市场愿意为特斯拉的软件业务赋予想象空间的原因之一。

更有意思的是，FSD与ChatGPT之间存在某种商业模式上的相似性。

ChatGPT帮助人们完成写作、编程、分析等认知任务；FSD帮助人们完成转向、变道、跟车等驾驶操作。

两者都在将原本由人类承担的部分工作，转化为可以按月购买的AI服务。

**未来AI商业化最重要的市场之一，可能就是人类原本需要投入大量时间和精力完成的工作。**

99美元的FSD，已经让消费者开始尝试为这种数字劳动力付费。

## 为什么FSD真正值钱的地方可能是Robotaxi？

目前的FSD仍然需要驾驶员监督，无法真正释放驾驶员的全部时间。

你可以减少大量重复的驾驶操作，却不能坐在驾驶座上安心睡觉、看电影或者处理工作。

但假如未来自动驾驶技术能够在足够广泛的场景下实现无人化，并获得相应的监管许可，整个商业模式就有可能发生变化。

私人汽车原本只是一个消费品，未来则可能成为能够参与运输服务、产生收入的资产。

网约车平台需要向司机支付劳动报酬，无人驾驶车队有机会降低这部分成本，但仍然需要承担车辆折旧、能源、保险、维护、清洁和运营管理等费用。

特斯拉真正想挑战的，可能远不止传统汽车行业。

![特斯拉 Cybercab：没有方向盘与踏板的无人驾驶出租车](/images/tesla-fsd-duan/fig-4.jpg)

它还可能参与网约车、出租车、汽车租赁以及其他出行服务市场的竞争。

这也是为什么单纯用传统汽车公司的估值体系研究特斯拉，容易遗漏它的潜在增长空间。

但反过来，如果投资者提前把尚未充分验证的Robotaxi商业利润全部计入估值，也可能严重高估特斯拉的价值。

投资者最终需要关注的，仍然是FSD付费渗透率、订阅留存率、安全表现、监管进度，以及无人驾驶业务真实的单位经济模型。

喜欢产品和买入股票，是两个不同的决策。

**好产品不一定是好生意，好生意也不一定是好价格。**

这恰恰也是段永平价值投资理念中值得学习的地方。

## 别忘了，这位司机真的没有驾照

段永平的段子虽然有趣，但特斯拉FSD的全称里，有一个经常被忽略的单词：Supervised。

Full Self-Driving (Supervised)，全自动驾驶能力监督版。

根据特斯拉官方说明，FSD能够辅助完成城市道路行驶、高速公路进出、变道、转弯和路口通行等操作，但这些功能并不会让车辆成为真正的无人驾驶汽车，也不会取代驾驶员的责任。

按照目前监督版的使用要求，你依然需要保持注意力，观察道路和周围环境，遵循车辆使用手册，并随时准备接管。

如果你准备去美国旅行，顺便租一辆带FSD的特斯拉体验，也建议提前确认几个问题：

- 租赁车辆是否已经开通FSD，而非只有基础辅助驾驶功能。
- 租车合同是否允许使用相应辅助驾驶功能。
- 保险保障范围、免责条款和事故处理方式。
- 当地驾驶资格要求，以及车辆功能的具体使用限制。

发生事故之后，责任如何划分，需要根据事故原因、当地法律、保险合同和具体证据确定。

千万不要因为它的名字叫Full Self-Driving，就误以为自己已经从驾驶员变成了乘客。

FSD越好用，人类越容易放松警惕。

这恰恰是监督式自动驾驶技术面临的一项重要挑战：如何让用户在长期顺利运行之后，依然保持对小概率危险事件的警觉。

绝大多数时候表现优秀，与能够安全地处理所有需要处理的情况，中间还有很长的距离。

## 最好的营销，是让用户离不开产品

回过头来看这件事，段永平最开始讨论的是手机。

他说折叠屏对自己帮助不大，已经换回了直板手机，因为钱包没地方放。

而在另一边，他却对特斯拉FSD表现出了持续的兴趣。

这两个看似毫不相关的消费选择，实际上反映出一种很朴素的产品评价逻辑。

技术先进不先进、产品贵不贵、是不是行业最新趋势，都可以放在一边。

关键在于，它究竟有没有改善自己的生活。

折叠屏解决不了自己的问题，就换回直板手机。

FSD能够改善自己的出行体验，到了夏威夷也想继续使用。

这种来自真实生活的选择，比发布会上的技术参数更有说服力。

特斯拉最理想的广告，或许就是越来越多的用户在出门旅行、购买下一辆汽车、选择租车服务时，主动问一句：

**这辆车有FSD吗？**

当消费者开始用软件能力筛选汽车时，汽车行业的竞争规则也就开始改变了。

至于段永平那位没有驾照的司机，按照99美元一个月计算，一年只需要1188美元，平均每天约3.26美元。

它还会随着软件更新不断学习新的驾驶能力。

当然，目前它还需要你亲自坐在驾驶座上监督，也远没有达到真正私人司机的全部能力。

但如果有一天，它真的可以独立、安全、合法地把你送到任何想去的地方，你觉得它还会只卖99美元一个月吗？

**如果是你，你愿意每月花99美元，请一个没有驾照的AI司机吗？**
