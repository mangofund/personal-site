# 宁德时代一天三封催款邮件？车企的钱到底卡在哪？

<div class="meta-line">2026.11.20 · 投资 · 阅读约 12 分钟</div>

11月18日，《21世纪经济报道》的一篇调查，把理想汽车与宁德时代之间的关系推上了热搜。

一名理想汽车供应部门员工透露，自从理想宣布扩大自有品牌电池的应用后，他每天至少收到三封宁德时代发来的催款邮件。

双方明明还是战略合作伙伴，怎么突然开始频繁催款？

更有意思的是，理想汽车并不缺乏现金储备。

根据今年二季度财报，截至6月底，理想汽车的现金、定期存款及相关金融资产储备约875亿元。

一家账上有875亿元的车企，为什么还会被供应商催款？

顺着这个问题，我查阅了理想汽车和宁德时代的财报、原始调查报道，以及工信部今年发布的供应商账期管理新规。

发现真正值得讨论的，是整个汽车行业的一种商业模式：

**车企可能在消费者付钱之后，仍然过了很久才向零部件供应商支付货款。**

但先说明一个事实。

所谓“一天三封催款邮件”，目前来自媒体采访中的员工陈述，没有公开的原始邮件、款项金额和合同到期信息，宁德时代与理想汽车也尚未就此作出完整的正式说明。

所以，我们不能认定理想汽车已经拖欠宁德时代货款，更不能把催款直接等同于资金链危机。

不过，这件事恰好让我们有机会拆解汽车产业链中最关键的资金流动问题。

## 买车的钱，究竟流向了哪里？

先用一辆售价30万元的汽车来理解。

消费者订车时可能支付少量定金，临近交付时支付剩余车款，金融机构也可能替贷款购车的用户向车企结算。

而车企在交车之前，已经向供应商采购了电池、电机、芯片、轮胎、座椅等零部件。

这些采购不一定需要立即付清现金。

假设车企向电池供应商采购一批价值1亿元的电池，约定验收后60天支付。

供应商先交付电池，车企完成生产并向消费者交车。

如果车辆销售回款发生在供应商付款到期前，车企就获得了一段可以使用这笔资金的时间。

对供应商而言，情况正好相反。

电池厂已经购买原材料、支付员工工资、承担生产费用，还需要等待车企付款。

这笔尚未收回的货款，在供应商资产负债表中可能表现为应收账款。

在车企资产负债表中，则可能表现为应付账款。

这种商业信用本身非常普遍，也具有合理性。

但当市场竞争激烈、企业不断要求降价、付款期限又持续延长时，供应商就会承担越来越重的资金压力。

## 理想汽车账上875亿元，为什么仍有付款压力？

看看理想汽车截至2026年6月底的财报。

| 财务指标           |       金额 |
| -------------- | -------: |
| 现金及现金等价物       | 401.18亿元 |
| 现金头寸（包括定期存款等）  |   约875亿元 |
| 应付账款及票据        | 387.56亿元 |
| 2026年第一季度经营现金流 | -60.91亿元 |
| 2026年第二季度经营现金流 |  +0.15亿元 |
| 2026年第二季度自由现金流 | -13.01亿元 |

其中需要特别区分，875亿元属于较宽口径的现金及金融资产储备，并非全部都是可立即使用的活期现金。

387.56亿元是理想对所有相关供应商的应付账款及票据总额，不能视为欠宁德时代的款项，也不代表全部已经逾期。

这些数字至少说明，理想拥有较大的资金储备，同时仍要管理庞大的供应商付款义务。

而从现金流看，公司的经营环境也发生了变化。

2026年第一季度，理想经营现金净流出约60.91亿元。第二季度虽转为正数，但只有1502.5万元。

公司解释，经营现金流变化受到客户收款和库存采购付款时间差的影响。

另外，理想第二季度汽车毛利率只有9.4%，明显低于2025年同期的19.4%。

这意味着车企每卖出一辆车，留给自己覆盖研发、营销和管理费用的利润空间变小了。

企业当然有动力更严格地管理每一笔采购款项。

但仅凭这些财务数据，还无法判断其对宁德时代是否存在逾期付款。

真正需要看的，是具体合同的付款条件、验收状态和应付款账龄。

## 汽车行业的账期，已经长到了什么程度？

把视野从理想扩大到整个行业，情况更加值得关注。

2026年8月，财联社根据Wind数据统计了14家主流上市车企。

截至6月底，这些企业的应付账款及票据合计约7825亿元。

按照该机构统计口径，相关车企平均应付账款周转天数达到187天，比2025年末延长约23天。

其中，理想汽车对应的周转天数约162天，比2025年末缩短约23天，反而是样本中少数改善的企业之一。

这里有一个容易产生误解的地方。

**财报中的应付账款周转天数，不等于每一张供应商发票的实际付款期限。**

周转天数通常根据应付账款余额和营业成本估算，还受到统计期间、业务结构及票据分类等因素影响。

例如一家车企的应付款余额很大，计算出来的周转天数可能很长，但其中部分合同尚未到期。

反过来，一家企业的平均周转天数并不高，也可能仍然存在某些被长期拖欠的供应商。

因此，187天不能直接解读为14家车企全部违反了60天账期规定。

但这些数字确实表明：汽车制造业的大量经营资金，长期停留在应付供应商款项这个环节中。

## 为什么大家承诺60天付款，供应商还在喊难？

2025年6月，17家重点汽车企业公开承诺供应商付款账期不超过60天。

2026年9月，工信部与市场监管总局又联合发布《关于推动汽车企业规范供应商账款支付 优化账期管理的通知》。

这次文件尤其值得研究，因为它开始深入规范实际操作环节。

例如汽车零部件送达后，一般生产性物料原则上应在三个工作日内完成验收，确需装车验证的零部件应在五个工作日内完成相应检查。

为什么监管连验收时间都要规定？

因为供应商实际拿到钱，需要经过多个步骤。

货物交付、验收、双方对账、确定金额、生成付款安排，最后完成支付。

如果合同约定账期从验收合格之日开始，但车企迟迟不验收，那么即使名义付款期限为60天，供应商也可能等待更久。

还有一个问题是付款工具。

银行承兑汇票、商业承兑汇票及供应链票据，都可能被用于企业间结算。

但对供应商来说，收到一张未来到期的票据，与立即收到可自由使用的现金，流动性并不相同。

如果供应商急需资金，可能需要提前贴现，并承担相应成本。

因此，新规明确要求规范支付方式，不得强迫供应商接受商业承兑汇票、供应链票据等非现金工具，同时规范付款期限和贴现成本安排。

还需要注意，针对中小企业的法定保护、车企对供应商作出的60天承诺，以及大型供应商之间的商业合同，适用条件并不完全相同。

宁德时代是大型企业，不能直接套用针对中小供应商的全部特殊保护条款。

判断其与理想之间的具体付款是否合理，最终仍要回到合同及适用规则。

## 理想为什么要降低对宁德时代的依赖？

如果只讨论付款，很容易忽略双方关系变化的另一条线索。

2025年9月，理想与宁德时代还签署了为期五年的战略合作协议。

但到了2026年9月，理想宣布以26.5亿元增资欣旺达动力，取得增资后约8.79%的股份。

同时，理想开始加快推广自有品牌电池。

这背后涉及车企越来越重视的供应链控制权。

动力电池是新能源汽车成本、续航、快充体验和安全性能的关键组成部分。

如果一家车企对单一电池供应商过度依赖，当供应能力、采购价格或技术路线出现分歧时，整车生产可能受到影响。

对理想来说，增加供应商、推动电池设计自主化，可以提高议价能力，也可能降低部分供应风险。

但所谓自研电池，需要区分电芯、模组、电池包、管理系统以及整车集成等不同环节。

采用自有品牌电池，不意味着企业已经独立生产全部电芯。

从宁德时代的角度看，事情则可能完全不同。

供应商为了满足车企需求，需要提前投入研发、产能和专门的工程团队。

《21世纪经济报道》称，宁德时代过去三年在理想项目中投入了近400名员工，双方还维持定期技术会议。

报道还提到双方曾存在一定的供应份额与返利安排，但具体合同条件未公开。

如果车企未来减少采购，供应商可能面临产能利用率和投资回收压力。

因此，供应关系变化可能让双方更加关注未结算款项、已经完成的开发工作，以及未来订单安排。

这是一种合理的商业解释，但目前没有公开证据证明所谓催款邮件的具体原因就是供应份额变化。

## 宁德时代自己也在承受回款压力吗？

再看宁德时代自己的财报。

截至2026年9月底，宁德时代应收账款约1129亿元，比2025年末的764亿元增长47.8%。

不过，公司同期营业收入也明显增长，不能仅凭应收账款增加就认定客户付款恶化。

而且，宁德时代的客户遍布不同车企和储能市场，这些应收账款不能直接归因于理想汽车。

更值得注意的是，宁德时代在供应链中也同时扮演两个角色。

它向车企销售电池，需要等待客户付款。

它又向上游采购锂盐、正极材料、负极材料、隔膜及设备，也拥有自己的应付账款和票据。

所以，资金压力可能沿着供应链继续传递。

车企延长付款，电池厂需要承担更多营运资金。

电池厂如果也延长对材料商的付款，材料商就需要承担更多融资压力。

而越往产业链上游，一些规模较小、资金储备有限的企业，抵御这种压力的能力可能越弱。

这也是为什么汽车行业的账期治理，已经不能只靠某一家企业主动承诺。

它关系到整条供应链能否正常运转。

## 为什么价格战最后可能演变成账期战？

汽车行业的价格竞争，表面上体现为消费者看到的终端价格下降。

但生产一辆车的成本，并不会因为车企降价就自动消失。

如果车企无法通过技术、生产和规模效率完全消化降价，就可能向供应商寻求更低的采购价。

当进一步降价越来越困难，付款条件也可能成为谈判内容。

例如供应商愿意接受较低价格，但要求更快回款。

或者愿意给予更长账期，但希望获得更高价格、更稳定的采购数量或其他合同保障。

两者本质上都涉及资金成本的分配。

对于一家现金充裕的车企，延迟支付一笔大额货款，可以暂时释放营运资金。

对于供应商，同样金额的延迟收款，却可能增加银行融资需求。

一旦供应商需要通过借款维持生产，融资成本最终仍有可能体现在零部件报价中。

因此，长期压低供应商价格和延长付款周期，未必能给整个行业创造更多价值。

它可能只是把经营压力转移到了更缺乏议价能力的一方。

严重时，供应商减少研发、缩减产能或出现交付风险，车企反而会承担更大的生产损失。

## 投资者真正应该检查什么？

这次事件给投资者提供了一个很好的研究切入点。

看车企财报，不能只看销量、营收和毛利率，还应该检查经营现金流与营运资金的变化。

如果一家车企销量增长，经营现金流也持续增长，同时应付账款周转天数保持稳定，通常更容易说明增长质量良好。

但如果公司利润增长主要伴随着应付账款快速增加、供应商付款持续延后，就需要进一步检查其现金流来源。

还可以观察应付账款及票据的结构变化。

一家公司减少现金付款、增加票据结算，可能改善当期现金流，但不意味着基础经营盈利能力同步提高。

对宁德时代这样的供应商，则应该关注应收账款增长是否与收入增长匹配、客户集中度是否变化、应收账款账龄是否恶化，以及经营现金流能否覆盖持续扩产。

而理想汽车还有一个明确的观察时间点。

公司已经公告，**2026年第三季度财报将于11月25日发布**。

届时最值得关注的，是现金储备、应付账款及票据、经营现金流，以及管理层是否进一步说明电池供应商合作和资金管理策略。

在这些信息出现之前，单凭三封催款邮件的说法，还不足以判断企业信用风险发生了重大变化。

---

回到最初的问题。

宁德时代为什么据称一天向理想发送三封催款邮件？

目前公开信息无法确认具体款项、是否逾期，以及邮件的真正目的。

但这场争议揭示了新能源汽车产业链的一种现实。

车企需要资金研发新车、建设工厂、发展销售网络，还要在激烈竞争中不断降低终端价格。

供应商则需要提前采购原材料、组织生产、承担研发及质量责任，并等待车企付款。

双方都希望拥有更多现金、减少风险，但资金总要由某一方先垫付。

**一家车企的财报可以有很多现金，仍然可能存在复杂的供应商付款安排；一家电池厂规模再大，也需要管理回款周期和客户信用风险。**

对投资者而言，真正需要警惕的，是那些依赖持续延长账期来维持现金流的商业模式。

因为这种模式能够延缓资金流出，却无法永久解决盈利和经营效率问题。

汽车行业经过多年价格战，下一阶段需要证明的，可能是整车厂和供应商能否在合理价格、合理账期和持续研发之间形成更稳定的利益分配。

**当消费者得到越来越便宜的汽车，究竟是谁在为这份便宜提前垫钱？**

这才是三封催款邮件背后更值得追问的问题。
