# 马斯克访华说要增产，但是中国的销量跌了15%：上海工厂的角色变了？

<div class="meta-line">2026.11.20 · 投资 · 阅读约 13 分钟</div>

11月19日，马斯克结束深圳的公开活动后，专程飞往上海，来到特斯拉超级工厂。

在深圳会见中国贸促会会长任鸿斌时，他表示特斯拉将继续提高在中国的产量，还称自己是中国的“超级粉丝”。

如果只看新闻标题，这似乎意味着特斯拉准备进一步押注中国市场。

但仔细翻看今年的销售数据，会发现一个很反常的现象。

**2026年前10个月，特斯拉在中国的零售销量下降了15%，上海工厂的整体批发交付量却增长了21.4%。**

为什么国内车卖得少了，上海工厂反而交付得更多？

答案藏在出口数据里。

今年前10个月，上海工厂出口42.1万辆，首次在同期累计口径下超过国内零售的39万辆。

这可能意味着，上海工厂在特斯拉全球体系中的角色，正在发生一次值得投资者重视的变化。

财报季真正决定股价的是什么，10 月那篇[特斯拉 Q3 财报前瞻：会飞的 Roadster 之后，真正决定股价的是什么](/investment/tesla/q3-earnings-preview)里拆过一次。

## 上海工厂增产，主要卖给了谁？

先看乘联会数据。

| 指标        | 2026年1—10月 |      同比 |
| --------- | ---------: | ------: |
| 上海工厂批发交付量 |   810,889辆 |  +21.4% |
| 中国国内零售量   |   389,905辆 |  -15.0% |
| 上海工厂出口量   |   420,984辆 | +101.3% |

这个表格揭示了一件事。

**特斯拉上海工厂今年的交付增长，几乎完全由出口增长支撑。**

2025年前10个月，上海工厂出口量约20.9万辆，占同期批发交付量的31.3%。

到了2026年，这个比例提高至51.9%。

也就是说，上海生产的Model 3和Model Y，已经有超过一半通过出口渠道运往海外。

10月份的数据更加极端。

当月上海工厂批发交付67,829辆，其中出口59,012辆，占比87%。

中国国内零售量只有8,817辆，同比下降66.1%，创下2022年7月以来的月度低点。

</div>

不过，不能仅凭10月一个月的数据就认定中国需求已经崩溃。

特斯拉长期存在按季度组织生产、出口运输和不同市场交付的节奏差异。

一个月出口占比异常高，可能受到集中装船和交付安排影响。

但把时间拉长到前10个月，中国内销下降15%、出口增长101%的趋势就更值得关注。

这说明特斯拉正在越来越多地依靠上海工厂满足海外市场需求。

需要注意，乘联会的出口数据反映车辆出境，并不等于每辆车都已经交付海外终端消费者。

海外库存与最终销售情况，还需要结合当地市场数据验证。

## 马斯克为什么还要强调中国增产？

要理解上海工厂的意义，首先要理解它在特斯拉制造体系中的地位。

2019年，上海超级工厂开始投产。

此后，特斯拉逐渐把它发展成全球最重要的Model 3和Model Y生产基地之一。

根据特斯拉2026年第三季度官方资料，上海整车工厂已经具备超过95万辆的年产能。

相比之下，柏林工厂的Model Y年产能超过37.5万辆。

上海工厂的优势，并不只是生产规模大。

还在于它已经形成高度本地化的供应链体系。

根据特斯拉近期披露的数据，上海工厂零部件本土化率达到98%，拥有超过400家中国本土一级供应商，其中60多家进入了特斯拉全球供应链体系。

注意，98%的零部件本土化率，并不意味着98%的整车成本都来自中国供应商。

但如此高的本地化程度，说明上海工厂在供应链组织、交付效率及配套能力方面已经建立了重要基础。

对于汽车制造来说，这非常关键。

因为生产成本除了原材料和人工，还受到运输距离、供应稳定性、零部件交付周期、库存和工厂利用率影响。

上海工厂已经积累了成熟的制造体系。

如果能够获得稳定订单，继续提高产量可能帮助特斯拉分摊固定成本，提高资本使用效率。

所以，马斯克强调在中国增产，有明确的产业逻辑。

但从目前官方资料看，特斯拉尚未公布这次增产需要新增多少设备、扩建多少车间，或者在什么时间完成。

**继续提高产量，可以通过提高现有产线利用率实现，并不一定意味着立即建设新工厂。**

## 出口越多，对特斯拉就越好吗？

不一定。

从生产端看，出口可以帮助上海工厂获得更多订单，减少因国内需求波动造成的产能闲置。

但从利润端看，出口还要面对物流、关税、汇率和海外竞争。

例如欧盟对中国制造的纯电动汽车实施反补贴贸易措施。

根据欧盟相关法规，特斯拉上海公司适用7.8%的特定反补贴税率，此外还涉及通常适用的进口关税及相关条件。

2026年欧盟部分法规还引入了符合条件的价格承诺豁免机制，因此具体进口成本需要按实际交易与适用规则判断。

这意味着，同样一辆上海生产的Model 3，出口到不同国家，最终利润可能存在明显差异。

另外，特斯拉在德国已经拥有柏林工厂。

如果上海出口的Model Y增加，而柏林工厂生产的Model Y减少，那么上海产量增长未必代表特斯拉全球销量同步增长。

它也可能是全球订单在不同工厂之间重新分配。

对于股东而言，最终应该关注的是公司整体创造了多少增量利润，而不仅是某一家工厂生产了多少辆汽车。

另一个需要注意的变化是，国际能源署在《Global EV Outlook 2026》中指出，中国品牌在欧盟从中国进口的电动车中，所占份额持续提高。

2025年，中国品牌在这一进口市场中的份额已经超过70%。

这意味着，上海工厂即使拥有较强的制造优势，也要在海外面对更多来自中国本土车企的竞争。

中国汽车供应链的竞争力，正在帮助特斯拉降低成本，同时也在帮助特斯拉的竞争对手成长。

## 国内销量下滑，特斯拉到底输在哪里？

中国新能源汽车市场的竞争已经进入了新阶段。

过去，Model 3和Model Y依靠电动化体验、品牌、效率和软件能力，建立了明显的产品优势。

但现在，比亚迪、小米、理想、小鹏、蔚来以及其他国内车企，都在持续改进产品。

消费者在20万至30万元的价格区间内，可以选择的车型越来越多。

而且，竞争已经深入到智能座舱、辅助驾驶、充电速度、空间、配置和售后体验。

特斯拉虽然仍然拥有品牌和制造体系优势，但这些优势不再保证国内销量持续增长。

今年10月30日，特斯拉在中国推出新的购车金融优惠，将部分Model 3和Model Y五年免息方案的最低首付款降至39,900元。

金融优惠可以降低消费者购买车辆时的资金门槛，但也可能意味着公司需要通过促销手段刺激需求。

需要注意，融资优惠的经济成本取决于具体金融合作安排，不能直接等同于相同金额的车辆降价。

而且，中国市场当前还有一个更深层的问题。

特斯拉长期希望依靠FSD辅助驾驶软件建立差异化优势。

但在中国，其相关功能、订阅服务及监管许可范围仍存在限制，尚未实现与部分海外市场完全一致的广泛开放。

马斯克此次到访上海工厂，虽然向员工介绍了辅助驾驶和人形机器人方面的进展，却没有公布新的中国FSD全面开放时间表。

因此，这次访华不能直接解读为FSD在中国获得了重大监管突破。

对于国内消费者来说，如果本土竞品已经提供足够有吸引力的辅助驾驶体验，特斯拉就需要继续在产品和价格上证明自己的竞争力。

## 上海工厂的角色正在发生什么变化？

我认为，可以从三个层次理解。

首先，它仍然是中国市场的重要整车生产基地。

但现在，海外订单已经成为支持工厂交付规模增长的重要来源。

其次，上海工厂越来越像特斯拉的全球制造与供应链中心。

超过400家本土一级供应商形成的产业网络，不只服务中国本土消费者，也参与特斯拉全球汽车供应链。

第三，上海正在同时承担汽车和储能产品的制造任务。

根据特斯拉第三季度投资者资料，上海Megapack储能工厂已经投产，规划年产能为20GWh。

这和Model 3、Model Y的整车产能属于不同业务，不能混为一谈。

但它意味着上海在特斯拉全球制造网络中的价值，开始覆盖汽车之外的大型储能设备。

而特斯拉正在布局的Robotaxi、Cybercab和Optimus等业务，其主要生产和技术投入安排目前仍集中在美国相关基地。

因此，马斯克到上海谈论机器人和辅助驾驶进展，并不代表特斯拉已经宣布在上海量产Optimus。

从目前公开信息看，更合理的判断是：

**上海正在从主要面向中国市场的整车生产基地，进一步强化为面向全球市场的制造、出口和供应链枢纽，并增加储能制造角色。**

但这种变化是过去几年逐步形成的，不能完全归因于马斯克11月19日这次访问。

## 增产10万辆，对TSLA估值意味着什么？

现在来到投资者最关心的问题。

上海继续增产，能不能让特斯拉股票更值钱？

我们可以做一个简化计算。

假设上海工厂未来每年额外生产并最终售出10万辆汽车。

再假设这些增量车辆的单车收入为20万元人民币。

那么新增汽车销售收入约为200亿元人民币。

但收入不等于利润。

如果扣除新增生产、销售及其他直接相关成本后，每辆车能够形成1万至3万元人民币的增量经营贡献，那么10万辆车对应的年度增量经营贡献就是10亿至30亿元人民币。

这只是示例。

真实情况还受到车型结构、销售价格、汇率、运输、关税、补贴、产能投资和其他固定费用影响。

而且，假设的新增车辆必须真正增加特斯拉全球最终销量，不能只是从其他工厂转移订单。

现在再看特斯拉自身的财务表现。

根据2026年第三季度报告：

| 财务指标          |   2026年Q3 | 同比变化 |
| ------------- | --------: | ---: |
| 总营收           | 280.46亿美元 | 基本持平 |
| 汽车业务营收        | 205.60亿美元 |  -3% |
| 汽车毛利率（剔除监管积分） |     18.1% |   上升 |
| GAAP营业利润      |   7.18亿美元 | -56% |
| GAAP归母净利润     |   7.87亿美元 | -43% |

这里有一个很值得注意的现象。

虽然汽车毛利率有所恢复，但公司整体营业利润却大幅下滑。

原因之一是研发和运营投入持续增加，尤其涉及自动驾驶、机器人和相关基础设施。

这说明特斯拉如今已经在同时投入多条业务路线。

投资者购买TSLA，实际上需要判断汽车、储能、Robotaxi和机器人等业务未来的综合现金流。

但不同业务的盈利确定性相差很大。

上海汽车工厂的生产能力和交付数据已经可以被验证。

Robotaxi和Optimus未来能够创造的商业利润，则仍然存在更大不确定性。

截至11月19日美股收盘，特斯拉股价约374.41美元，市值约1.48万亿美元。

对这样一家公司来说，上海工厂即使额外贡献几十亿元人民币经营利润，也无法单独解释其庞大市值。

真正影响长期估值的，是它能否持续扩大现金流，并且让新的技术业务创造出足够高的资本回报。

## 增产最值得关注的，可能是利润率

如果我是长期投资者，我会重点观察三个变化。

首先，上海工厂的交付量增长，是否真正转化成全球终端销量增长。

如果出口增加主要来自海外消费者购买更多特斯拉汽车，这是积极变化。

但如果只是海外渠道库存增加，或者其他工厂减少生产，意义就没有看起来那么大。

其次，汽车毛利率能否在增加销量的同时保持稳定。

假设工厂交付增长20%，但为了争取订单持续降价，最终单车利润大幅下降，那么销量增长未必创造更多股东价值。

第三，中国供应链的效率改善能否复制到其他业务。

例如特斯拉将成熟的采购、制造与成本控制方法用于储能产品，帮助Megapack降低制造成本。

如果这种能力能够产生持续的全球竞争优势，价值可能比单纯增加一部分Model Y产量更大。

不过，上海工厂的单独经营利润和单车成本，并没有在特斯拉财报中完整披露。

所以我们不能直接声称上海制造的汽车一定比美国或德国工厂更赚钱。

能够确认的是，上海具备较大的产能规模和高度本地化供应链，这为其形成成本竞争力提供了条件。

真正的利润优势，还需要更多可比较的经营数据证明。

## 马斯克这次访华，还释放了什么信号？

过去几年，马斯克多次访问中国。

但这次有一个值得注意的细节。

11月19日，他在深圳参加相关活动后，又专程飞往上海工厂。

特斯拉全球副总裁陶琳透露，马斯克希望当面感谢亚太和中国团队，并高度评价上海工厂的制造和执行能力。

这至少说明，上海在特斯拉全球经营中的地位仍然非常重要。

不过，投资者需要区分公开表态和实际资本投入。

“继续提高产量”，是一项方向性表态。

新建产线、提高设备利用率、追加投资、扩大零部件采购，则属于不同的经营行为。

如果未来特斯拉正式公布上海新增产能计划，或者实际交付量持续突破现有水平，才有更充分理由判断上海制造业务进入新的扩张阶段。

至于访华是否会带来FSD审批突破、新车型投产，或者机器人生产基地落地，目前没有足够公开证据。

这些都应当作为待验证事项，而不能提前写进投资预测。

## 上海工厂越重要，特斯拉面临的风险也越集中

上海工厂的优势正在进一步增强，但这还意味着特斯拉的全球汽车供应对中国制造体系的依赖程度较高。

当国际贸易政策、运输渠道或者供应链发生变化时，这种集中度可能放大风险。

另一方面，继续向海外出口汽车，也会让特斯拉与更多中国品牌在全球市场直接竞争。

竞争的结果，可能推动特斯拉进一步提高制造效率，也可能压缩产品售价和利润率。

这就是上海工厂目前面临的双重现实。

它帮助特斯拉利用中国制造体系服务全球市场。

与此同时，中国汽车产业整体能力的提升，也正在改变特斯拉所面对的竞争格局。

所以，我认为马斯克这次访华，对投资者最重要的信息，并不是他又一次表达了对中国的喜爱。

真正值得关注的是，上海工厂已经越来越依靠海外市场支撑增长。

而特斯拉未来需要证明的是：这种出口增长到底创造了多少新的全球需求，又能留下多少实际利润。

**如果上海工厂不断增产，但中国内销持续下降、海外售价承压、整体利润率没有改善，那么增产的估值意义就很有限。**

反过来，如果上海能够在出口增长的同时维持成本优势，储能业务也形成稳定的盈利能力，它就可能继续增强特斯拉的长期现金创造能力。

过去，我们经常讨论特斯拉在中国到底能卖多少辆车。

现在可能需要开始问另一个问题：

**中国制造，究竟能够为特斯拉的全球业务创造多少利润？**

这比单纯统计上海工厂每年下线多少辆Model 3和Model Y，更能决定TSLA未来的投资价值。
