# 技能商店

三步装好一个技能：

1. **复制或下载**——在下面挑一个技能，点「复制技能」或下载 ZIP。
2. **放进 Agent**——把 SKILL.md 放进支持 Skills 的 Agent（Claude Code、Muse、Cursor 等）。
3. **验证**——用自己的项目跑一次，结果仍需在你的环境中验证。
