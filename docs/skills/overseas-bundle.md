# 出海包

出海站分两段：先拿到流量，再把流量变成付费。这个包把两段各交一个技能做：新词上站负责把待验证的搜索需求当天做成落地页、见流量再补登录与支付；变现转化负责流量进来之后的停留、定价、留存与支付埋点。

## 包含的技能

- [出海新词上站](/skills/overseas-new-keyword-launch)：把待验证的搜索需求转成可发布的落地页，并规划上线后的 SEO/GEO 验证。
- [出海变现转化](/skills/haiwai-monetize-convert)：假生成、锚定定价、留存入口与 Stripe 埋点风控，提升付费转化。

## 适用人群

在做副业出海站、已经有站或正准备上站、想从首流量走到首付款的人。
