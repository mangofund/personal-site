# 写作包

写东西时常卡在三个地方：成稿一股机器味、想说的事说不明白、好内容只发了一个地方。这个包把三件事各交一个技能做：先把成稿里的机器味清掉，再把表达收成一句一件事，最后把同一份内容写成口播长文、分发到视频与文章。

## 包含的技能

- [去AI味写作](/skills/de-ai-writing)：按你的口吻写，或把成稿里的机器味清掉。
- [直说](/skills/zhishuo)：先给结论，再给理由：一句一件事，数字代替形容词。
- [口播分镜](/skills/koubo-storyboard)：把复盘/研报写成口播体长文，并按叙事拐点出证据帧插图；同一剧本分发到视频与 X Article。

[下载写作包 ZIP](/skills/zips/writing-bundle.zip)

## 适用人群

经常要写公众号文章、投资简报或口播长文，又想让成稿听起来像自己说话的人。

## 安装

解压 ZIP，把需要的技能文件夹放进你所用 Agent 的 skills 目录（不同 Agent 的路径不同，以你所用工具的文档为准）。各技能的具体用法见各自的 SKILL.md；口播分镜另附 INSTALL-MUSE.md。
