# MCP Starter Bundle

Before looking for a ready-made connector, the first step in connecting a third-party service to an agent is learning how to connect one: use the official MCP server or API, grant only least privilege, write down the tool schema and error handling, and verify with one harmless read. This bundle is that first step.

## Skills included

- [Custom Connectors & MCPs](/en/skills/custom-connectors-mcp): Connect third-party services with least privilege, clear tool schemas, error handling, and tests.

This bundle currently contains one skill. Amap, Didi, and Luckin are MCP connector documents, not skill files, and there is no matching skill on the site to bundle; there is also no second MCP-related skill on the site, so no filler member was added.

## Download

[Download the MCP Starter Bundle ZIP](/skills/zips/mcp-starter-bundle.zip)

The ZIP contains the full files of the Custom Connectors skill (SKILL.md), with a README at the root listing the members and how to install them.

## Who it is for

People connecting a third-party service to an agent for the first time and wanting to set the connector up with least privilege.

## Install

Unzip the file and place the skill folder into your agent's skills directory (the path differs by agent; follow your tool's documentation). The SKILL.md explains its usage.
