# Skills Store

Not a pile of generic prompts. Reusable workflows agents can execute, covering AI project delivery, website launch QA, growth, UI, content, integrations, browser automation, and data analysis.

Three steps to install a skill:

1. **Copy or download** — Filter by scenario, then pick a skill below and copy it or download the ZIP.
2. **Add it to your agent** — drop the SKILL.md into an agent that supports Skills (Claude Code, Muse, Cursor, and others).
3. **Verify** — run it on your own project and check the results in your own environment.
